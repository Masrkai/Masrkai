# Masrkai

**Systems Engineer & Developer** · Egypt 📍

I build at the intersection of low-level systems, infrastructure, and developer tooling 
where correctness, performance, and reproducibility matter most. 

> *Freedom can't co-exist with limitations.*

### Core Focus Areas
- **Systems Programming:** C, C++, Rust
- **Infrastructure:** NixOS, declarative configurations, custom derivations
- **Security & Networking:** Traffic shaping, OSINT, secure memory management
- **Low-Level Engineering:** OS simulation, IPC, memory wiping.
